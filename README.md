# HUB

אתר ההורדות המשותף של TALI, RONNY ו־A.NAV.

האתר סטטי ומפורסם אוטומטית ל־GitHub Pages בכל push לענף `main`.

## מבנה

- `/` — TALI
- `/ronny/` — RONNY
- `/a-nav/` — A.NAV
- `/assets/` — עיצוב וסמלים משותפים

## פיתוח מקומי

אפשר לפתוח את `index.html` ישירות בדפדפן או להגיש את התיקייה באמצעות שרת סטטי.

## מחשב מול טלפון

- **מחשב:** TALI היא אפליקציה, ולכן יש לה כפתור הורדה ל־Windows. RONNY ו־A.NAV הם אתרים, ולכן יש להם כפתור ״פתיחה״ שמקשר לאתר.
- **טלפון** (מסך עד 760px, או מסך מגע בלי עכבר): שלושתם נפתחים כאפליקציות רשת, עם כפתור ״הוספה למסך הבית״. הכפתור פותח חלונית עם ההוראות לאייפון או לאנדרואיד ועם קישור לאפליקציה (`assets/add-home.js`). HUB לא יכול להתקין אתר אחר בעצמו, ולכן ההתקנה נעשית מתוך האפליקציה.
- הכתובות: Tali `https://taliwrite.netlify.app/app/`, RONNY `https://dev--ronnytripplanner.netlify.app/`, A.NAV `https://dev--anavfin.netlify.app/`. כל כתובת מופיעה פעמיים בדף שלה (בכפתור הפתיחה וב־`data-app-url`).
